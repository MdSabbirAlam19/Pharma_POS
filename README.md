# PharmaPOS Pro v2.5 — Enterprise Pharmacy Management System

## Quick Start
```bash
pip install flask flask-cors bcrypt pyjwt
python3 app.py
```
Then open: http://localhost:5000

## Features
- ✅ Full POS Billing with receipt printing
- ✅ FEFO Inventory (First Expiry First Out)
- ✅ Batch & Expiry Tracking
- ✅ Purchase Orders & GRN
- ✅ Customer CRM + Loyalty Points
- ✅ Supplier Management
- ✅ Sales History & Returns
- ✅ Financial Reports (P&L, VAT, Revenue)
- ✅ Inventory Reports (Dead stock, Fast moving)
- ✅ Expiry Monitor with alerts
- ✅ User Management & Roles
- ✅ Full Audit Log
- ✅ JWT Authentication
- ✅ Responsive (Mobile + Desktop)
- ✅ Keyboard shortcuts (F1=POS, F2=Search, Esc=Close)

## Keyboard Shortcuts
- F1 → POS Billing
- F2 → Search medicines
- Esc → Close modal
